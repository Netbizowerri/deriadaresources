# Deriada Global Resources Limited Website

Production-ready React 19 + Vite 6 + TypeScript single-page web application for Deriada Global Resources Limited.

## Tech Stack
- React 19
- Vite 6
- TypeScript
- React Router DOM 7
- React Helmet Async (SEO)
- Framer Motion (animations)
- React Hook Form (validation)
- Lucide React icons
- Tailwind CSS via CDN

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Notes
- Contact form posts to Formspree endpoint in `src/context/SiteContext.tsx`.
- Replace `https://formspree.io/f/your-form-id` with your real endpoint before deployment.
